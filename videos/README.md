# מנוע סרטונים – רוני מודן · שחקים

סרטוני "טיקטוק" אנכיים למתמטיקה: HTML שעובד בלי אינטרנט (להקרנה על הלוח, עם כפתור "למורה")
ו-MP4 עם מוזיקה וצלילים (לשליחה ישירה בוואטסאפ).

## פרק חדש = תסריט בלבד
1. מעתיקים תיקייה ב-`episodes/` ומשנים `meta.json`, `episode.js` (שלבים לפי זמן), `teacher.html` (רציונל פדגוגי).
2. `python3 build.py episodes/<שם> out` → קובץ HTML אחד.
3. `python3 record.py out/<שם>.html out/<שם>.mp4` → MP4 1080×1920 עם פסקול (פריים אחר פריים, סנכרון מדויק).

## רכיבים (V.*)
כוסות-חלקים `cups/fill/hl/pairs/wobble` · טבלת העוגן `table/tset/anchor/fac/tcol` · שבר עם גורם הכפלה וקשתות `fracScale`
· פעולות + − · : `ops/opsMark/opsGood` · דלת תלת-ממד `doorOpen` · מפתח זהב `#key` · שעון עצר `clock` · מעקב דלתות `tracker`
· צלילים `sfx(pop|wrong|right|whoosh|tick|ding|go)` · מוזיקת רקע מקורית (מולחנת בקוד, בלי זכויות יוצרים).

## כללים קבועים
כפל = נקודה (·) · חילוק = : · יחס בלי רווחים (2:3) · נתון בצהוב, עוגן במסגרת ירוקה, גורם ההכפלה באדום עם קשתות
· כל טעות נפוצה מוצגת ומופרכת בעיניים · מטאפורה פותחת, מושג מדויק סוגר.
