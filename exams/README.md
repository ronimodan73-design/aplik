# מחולל המבחנים ודפי העבודה של רוני
דף אחד: exams/generator.html. בוחרים כיתה, נושאים, ואם מכינים מבחן או דף עבודה, ומדפיסים.

- מבחן: עמוד פתיחה (פרטים, הנחיות, טבלת ניקוד, משפט הנעה), חלק לכל נושא וחלק אוריינות וחשיבה,
  ניקוד לפי רמה שמסתכם ב־100 בדיוק, מקום כתיבה, טור א׳ וטור ב׳ (אותו מבנה, שאלות שונות), ודף תשובות ומחוון.
- דף עבודה: דף לכל נושא, תיבת "השיטה", 4 רמות חשיבה (★ עד ★★★★), ודף תשובות.
- לוגו שחקים ושורת כותרת בראש כל עמוד מודפס, ו"עמוד X מתוך Y" בתחתית (Chrome במחשב).

## הוספת נושא או כיתה = קובץ מאגר אחד
קובץ חדש ב־exams/bank/<id>.js (דוגמה: h8_ratio.js). כל שאלה:
{lv: 1-4, t: 'השאלה', a: 'התשובה', r: 'calc'|'why', lit: 1}
- lv: 1 ידע · 2 יישום · 3 הבנה · 4 חשיבה מסדר גבוה ואוריינות (רצוי 5 שאלות לפחות בכל רמה, בשביל שני טורים)
- {…} ביטוי מתמטי שנקרא משמאל לימין · [3/7] שבר מאונך · : לחילוק · × לכפל · יחס בלי רווחים 3:5
- r: calc מוסיף "הציגו את דרך החישוב", why מוסיף "נמקו" · lit: שאלה מהחיים (מועדפת בחלק האוריינות)
- grade: 'ז' או 'ח'. כיתה ז׳ נפתחת בממשק ברגע שיש לה מאגר אחד.

בנייה:  python3 exams/factory/build.py
בדיקה:  python3 exams/factory/verify.py <תיקייה>   (שגיאות, ניקוד 100 בכל טור, בלי שאלות כפולות, בלי שברים עם / , ושומר PDF)
