# מפעל דפי תרגול + מצגת לטלפון (רוני מודן · שחקים)

לכל סדרת שיעורים כותבים רק את `content.py`. כל השאר מוכן:

| קובץ | מה הוא עושה |
|---|---|
| `content.py` | השאלות, התשובות ומפרט השרטוט לכל שאלה (`d=('adj',48)` וכו׳) |
| `diagrams.py` | שרטוטים מדויקים לפי המידה: צמודות, קודקודיות, משולשים, מרובע, מערכת צירים, ציר מספרים |
| `build_sheets.py` | דף A4 להדפסה (index.html): יישור לימין, לוגו, שדה "שם" בלבד, שורות כתיבה שממלאות את העמוד, דף תשובות |
| `build_deck.py` | מצגת לטלפון (deck.html): שאלה במסך, החלקה, "הצגת תשובה" |
| `verify.py` | בדיקה: אין גלישת עמוד, מספר השורות בכל שאלה, ויוצר את practice.pdf |
| `mobile_patch.py` | מוסיף שכבת טלפון למצגות WOW קיימות (decks/…) |

הרצה:
```
python3 build_sheets.py OUT/index.html
python3 build_deck.py OUT/deck.html
python3 verify.py OUT/index.html OUT/practice.pdf x
```
שיעור שלא נכנס בעמוד אחד: `L[-1]['split'] = True` (בכיתה ובבית בשני עמודים, שרטוטים גדולים).
כפל = נקודה (·), חילוק = נקודתיים (:).
