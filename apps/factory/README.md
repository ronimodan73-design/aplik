# המפעל של רוני – אפליקציות תרגול
אפליקציה חדשה = קובץ תוכן אחד בתיקייה apps/content (שאלות + הסבר מונפש).
המפעל מוסיף לבד: תפריט, 4 שלבים × 20 שאלות, חימום, מבחן מדורג (16), דוח עם ציון,
עבודה בלי אינטרנט, התקנה למסך הבית, נגישות, וקרדיט "ערכה: רוני מודן · שחקים".

בנייה:   python3 apps/factory/build.py apps/content/<id>.js
בדיקה:   python3 apps/factory/verify.py <id> <תיקיית צילומים>
קישור:   https://htmlpreview.github.io/?https://github.com/ronimodan73-design/aplik/blob/main/apps/<id>.html
         (אחרי הפעלת GitHub Pages: https://ronimodan73-design.github.io/aplik/apps/<id>.html)

קבצי תוכן קיימים: t9_iso, dist, gcf, eq, h8_parallel, h8_lines (הישר והגרף), z7_q1 (הרביע הראשון)

## בנייה הדרגתית (נוסף באוקטובר 2026)
- סולם קבוע בכל שלב: ב־LEVELS כותבים ladder:[{g, n, h, a}] – g מחולל, n כמה שאלות, h רמז (2 גלוי, 1 בלחיצה, 0 בלי), a:0 מבטל את שלב "מה השאלה שואלת".
- "מה השאלה שואלת?": שאלה מחזירה ask:{text, choice, correct, diag} – התלמיד בוחר קודם את המשמעות, ורק אז פותר. לא מופיע במבחן.
- שאלה בצעדים (כמו שאלת מבחן ארוכה): steps:[{text, short, ans/choice, hint, lines, rule, diag, dia?}] על גרף אחד (dia של השאלה). נקודה רק אם כל הצעדים נכונים בניסיון הראשון.
- רמז: hint בשאלה (ברירת מחדל: rule).
דוגמה מלאה: content/h8_lines.js (chain7, chain6, ASK_*).

## בדיקת הבנה אחרי כל הסבר (נוסף ב־30.10.2026)
- אחרי כל כרטיס הסבר: 3 שאלות "בדיקת הבנה" על מה שהוסבר בכרטיס. טעות ← משוב + "זוכרים מההסבר" + שאלת ייצוב נוספת (עד 2 לכרטיס).
- השאלות נבחרות אוטומטית מהשאלות הקיימות שמשויכות לכרטיס (rc / APP.rc).
- כרטיס בלי שאלה משויכת: כותבים בסוף קובץ התוכן  RECAP[n].chk=[gen1, gen2].
- verify.py עובר על כל בדיקות ההבנה ומדווח "understanding checks" (כל כרטיס חייב ציון, לא NO-CHECK).
