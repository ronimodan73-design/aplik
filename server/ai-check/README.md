# בדיקה חכמה של הטיוטה (🤖 תבדקו לי)

האפליקציה שולחת את הטיוטה (או צילום מחברת) + שלבי הפתרון הנכון → שרת ביניים (Cloudflare Worker, חינם) → Gemini (תשלום זעיר) → תשובה עדינה בעברית: באיזה שלב כנראה הטעות.

## הפעלה (פעם אחת)
1. Google AI Studio: יוצרים מפתח API, ומפעילים חיוב (Paid tier – הנתונים לא משמשים לאימון). מגדירים תקציב חודשי.
2. Cloudflare (חשבון חינמי): Workers → Create → מדביקים את worker.js → Deploy.
3. Settings → Variables: GEMINI_KEY (Secret), MODEL = gemini-2.5-flash, DAILY_LIMIT = 300.
   אופציונלי: KV namespace בשם COUNTER מחובר ל־Worker (לתקרה יומית).
4. מעתיקים את כתובת ה־Worker אל apps/factory/config.json → "ai_url", ובונים מחדש את כל האפליקציות.

## בטיחות ועלות
- המפתח נשמר רק בשרת. הבקשות מתקבלות רק מהאתר של רוני.
- לא נשלח שם תלמיד – רק התמונה והשאלה.
- תקרה יומית + תקציב חודשי בגוגל.
- בלי אינטרנט / בלי config – הכפתור מוסתר, ו"איפה טעיתי?" ממשיך לעבוד.
